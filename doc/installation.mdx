Agent SDK is a Lua library with no plugin dependencies. Your plugin lists it as a dependency, and your users install it alongside your plugin. Every plugin built on it shares the one install.

## Requirements

- Neovim nightly (0.13-dev), as the SDK is built on `vim.async`
- `curl`, for HTTP adapters
- For ACP adapters, the agent itself. See [Claude Code](/configure/providers#claude-code)

Put these in your plugin's README, as your users need them too.

## Add it as a dependency

Tell your users to install Agent SDK with your plugin:

<Tabs>
  <Tab title="vim.pack">
    ```lua
    vim.pack.add({
      "https://github.com/olimorris/agent-sdk.nvim",
      "https://github.com/you/your_plugin",
    })
    ```
  </Tab>
  <Tab title="lazy.nvim">
    ```lua
    {
      "you/your_plugin",
      dependencies = { "olimorris/agent-sdk.nvim" },
    }
    ```
  </Tab>
</Tabs>

## Set up an adapter to develop with

Your plugin uses whichever adapter the user names, so you need one of your own to try it. Add one to your Neovim config:

```lua
require("agent_sdk").setup({
  adapters = {
    claude_code = {
      base = "acp",
      commands = { default = { "claude-agent-acp" } },
    },
  },
})
```

This one runs Claude Code. See [Claude Code](/configure/providers#claude-code) to install it and sign in, and [Configure adapters](/configure/adapters) for every other option. Then build your first plugin with the [quickstart](/build/quickstart), or by hand with the [chat plugin walkthrough](/walkthroughs/chat-plugin).
